# تطبيق رصد درجات الملف الشهري (Rasd Desktop App v3.0) 📊🎓

**تطبيق رصد** هو النظام المعياري المتكامل لإدارة ورصد وتجميع درجات الملف الشهري وبنود التقييم للمرحلتين الابتدائية والإعدادية بالمدارس الرسمية واللغات وخاصة المدارس المصرية اليابانية. صُمم التطبيق خصيصاً ليعمل بكفاءة عالية على أجهزة سطح المكتب (Linux & Windows) مع التزام كامل بالضوابط والتعليمات الوزارية المعمول بها دون أدنى تقريب أو جبر للكسور.

---

## ✨ أهم مميزات التطبيق (Key Features)

- ⚡ **شاشة الرصد السريعة التفاعلية**:
  - جدول تفاعلي ذكي شبيه ببرنامج Excel يدعم التنقل الكامل بواسطة أسهم الكيبورد (↑, ↓, ←, →, Enter, Tab).
  - احتساب المجموع الدقيق لكل شهر بدقة متناهية ودون جبر الكسر.
  - خيار عرض **`متوسط الترم (الـ 3 شهور معاً)`** كـ تبويب مستقل يوضح متوسط كل بند تقييم على حدة لكل طالب طوال الفصل الدراسي.

- 📄 **إصدار وطباعة إشعارات درجات الطلاب (PDF & Print)**:
  - طباعة وتصدير **إشعار درجات تقييم الملف الشهري** لكل شهر منفصل أو لمتوسط الترم الكلي بحسب الاختيار.
  - إمكانية إضافة وتخصيص اسم المدرسة بحرية دون أسماء فرضية.
  - إزالة التوقيعات الخاصة بالكنترول والإبقاء فقط على التوقيعات المعتمدة للملف الصفّي (`معلم / معلمة المادة` و `يعتمد مدير المدرسة`).

- 📑 **كشوف الرصد المجمعة (Master Grade Roster)**:
  - كشف رصد مجمع لجميع المواد الدراسية للمرحلة كاملة أو لفصل محدد بنمط أفقي (Landscape).
  - جلب الدرجات الحقيقية مباشرة من قاعدة البيانات SQLite دون أي قيم افتراضية.

- 📥 **استيراد وتصدير شيتات Excel**:
  - تصدير كشوف الدرجات بنطاق شامل (المرحلة كاملة أو فصل محدد) بنفس الهيكلية المعيارية.
  - استيراد تفاعلي مع معاينة مسبقة لكشف أي أخطاء أو قيم غير صحيحة، مع التحديث والطلب الحصري للطلاب المدونين بالشيت المستورد وتحديث درجات شهرهم دون المساس بالآخرين.

- 🏫 **دعم كامل لكافة المراحل والمواد**:
  - الصفوف من الأول إلى الثالث الابتدائي (المواد الأساسية + أنشطة التوكاتسو والتربية البدنية).
  - الصفوف من الرابع إلى السادس الابتدائي، والصفوف الإعدادية.
  - خيار المدارس اللغات (إضافة مادة اللغة الإنجليزية الإضافية تلقائياً عند تفعيل المدرسة لغات).

## 🛠️ التقنيات المستخدمة (Tech Stack)

| التقنية | الاستخدام |
| :--- | :--- |
| **Flutter 3.13+** | إطار العمل الرئيسي لبناء واجهة المستخدم على سطح المكتب |
| **SQLite / sqflite_ffi** | قاعدة بيانات محليّة سريعة ومحمية لحفظ السنوات الدراسية والسجلات |
| **Provider** | إدارة حالة التطبيق (State Management) |
| **PDF & Printing** | بناء وتصميم وتقسيم صفحات الـ PDF والطباعة المباشرة |
| **Excel (xlsx)** | إنشاء وتحديد ومعالجة ملفات الإكسيل استيراداً وتصديراً |
| **GitHub Actions** | البناء التلقائي ورفع الحزم التنفيذية لـ Linux و Windows |

## 🚀 كيفية التشغيل والبناء محلياً (Local Development)

### 1. المتطلبات السابقة:
- تثبيت Flutter SDK 3.13 أو أحدث.
- حزمة C++ Desktop Development (لإصدارات Windows) أو مكتبات `clang cmake ninja-build libgtk-3-dev` (لإصدارات Linux).

### 2. خطوات التشغيل:
```bash
# استنساخ المستودع
git clone https://github.com/darshstudio/rasd-months.git
cd rasd-months

# تثبيت الحزم والمكتبات
flutter pub get

# تشغيل التطبيق في وضع التطوير
flutter run -d linux # أو windows
```

### 3. بناء النسخة التنفيذية للإنتاج:
```bash
# بناء حزمة Linux
flutter build linux --release

# بناء حزمة Windows
flutter build windows --release
```

## 📦 حزم البناء والتحميل التلقائي (CI/CD Artifacts)

يحتوي المستودع على سير عمل **GitHub Actions** مُعد مسبقاً في الملف [`.github/workflows/build.yml`](.github/workflows/build.yml). عند رفع أي التزامات جديدة (Push)، يجرى البناء التلقائي للحزم التنفيذية لكل من:
- **Linux 64-bit Bundle** (`.tar.gz`)
- **Windows 64-bit Bundle** (`.zip`)

يمكنك الانتقال إلى تبويب **Actions** في مستودع GitHub وتحميل الملفات التنفيذية جاهزة للاستخدام بدون الحاجة لبيئة تطوير.
