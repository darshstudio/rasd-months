ضبط اتجاه طباعة إشعارات الطلاب وكشوف الرصد لتخرج دائماً من اليمين لليسار باتجاه عربي صحيح دون أي تداخل في النصوص أو الأرقام.

📊 استيراد وتصدير Excel
تحديث منطق الشيت الأسبوعي لـ 4 تبويبات

في حالة استيراد شيت أسبوع واحد، يتم حسابه مباشرة كـ الشهر كامل دون تقسيم، وجعل عمود اختبار الشهر حصرياً في التبويب الرابع (الأسبوع 4).

⚡ تحسين واجهة الرصد
إزالة الأعمدة المكررة وتوسيع الجدول

حذف عمود "مجموع البنود" لتوفير المساحة وتسهيل عملية الرصد اليومي والأسبوعي دون أي تشتيت للمعلم.

🛡️ استقرار القوائم
معالجة طفح القوائم المنسدلة (Dropdown Fix)

إصلاح خطأ Overflow في القوائم المنسدلة عند اختيار أسماء الطلاب الطويلة مع اقتطاع سلس بـ Ellipsis لضمان مظاهر مرئية راقية.

⚙️ بناء تلقائي GitHub Actions
خط إنتاج وتوزيع آلي (CI/CD Pipeline)

إعداد سيناريوهات البناء التلقائي للتطبيق وتوليد حزم الويندوز (.exe) المضمن بها C++ Runtime وحزم لينكس (.deb, .rpm, .tar.gz).

مواصفات الأجهزة ومتطلبات التشغيل (Minimum Requirements)

تم تصميم وتعميم تطبيق رصد الشهري ليعمل بكفاءة فائقة وسرعة عالية على مختلف أجهزة الكنترول

نظام التشغيل (OS)
Windows 10 / 11 (64-bit) أو Linux (Ubuntu 20.04+, Debian, Fedora, Arch)
المعالج (CPU)
Intel Core i3 / AMD Ryzen 3 أو أي معالج ثنائي النواة بتردد 1.8GHz أو أعلى
الذاكرة العشوائية (RAM)
2 جيجابايت كحد أدنى (يُنصح بـ 4 جيجابايت لأفضل استجابة وأداء)
المساحة التخزينية (Disk)
200 ميجابايت مساحة فارغة للتطبيقات وقواعد البيانات المدرسية المحلية
الشاشة والعرض (Display)
دقة 1024×768 كحد أدنى (يدعم الشاشات المحمولة 12"-14" ودقات Full HD و 4K)
المكتبات والملحقات
مدمج تلقائياً مع C++ Runtime (v1.0.1) لتثبيت مباشر بدون طلب أي برامج إضافية

تجربة مستخدم سهلة ومصممة لمساعدة المعلمين في إنجاز الرصد بأقل جهد

1
اختر العام والصف الدراسي
حدد العام الدراسي والفصل، واختر المرحلة (ابتدائي أو إعدادي) ليقوم النظام بتهيئة المواد تلقائياً.
2
ارصد الدرجات أو استورد Excel
أدخل الدرجات مباشرة بالتنقل بأسهم الكيبورد، أو قم باستيراد كشف Excel شهري أو تفصيلي لـ 4 أسابيع.
3
اطبع الكشوف وتصديـر النتائج
استخرج إشعارات التقييم الشهري للطلاب (PDF)، أو اطبع كشف الرصد المجمع لكافة المواد بضغطة زر.
